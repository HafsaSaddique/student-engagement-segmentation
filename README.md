\# Bright Future School — Student Engagement Segmentation



\## Project Overview



Bright Future School wants to understand student engagement patterns using attendance, academic performance, and extracurricular participation. This project prepares student engagement features as the foundation for later segmentation using K-Means clustering.



\*\*Data note:\*\* The dataset is synthetic and was generated by `make\_raw\_data.py`. It does not contain real student records.

\## Requirements



\- Python 3

\- pandas

\- Jupyter Notebook (for notebook exploration)



Install the required packages:



```bash

python -m pip install pandas numpy jupyter

```



\## Generate the Synthetic Dataset



From the project root, run:



```bash

python make\_raw\_data.py

```



This generates 300 synthetic student records in `data/raw/raw\_student\_data.csv`.



\## Prepare the Student Data



Run:



```bash

python prepare\_student\_data.py

```



The script reads the raw CSV, handles missing values, calculates the engagement features, and saves:



`data/cleaned/cleaned\_student\_data.csv`



\## Features



\- \*\*StudentID:\*\* Unique synthetic student identifier.

\- \*\*AttendanceRate:\*\* DaysPresent divided by DaysTotal.

\- \*\*AvgGrade:\*\* Mean of MathScore, EnglishScore, and ScienceScore.

\- \*\*ExtracurricularCount:\*\* Number of listed clubs or activities.



Missing attendance and Math scores are imputed with their respective medians. Empty club entries are treated as zero activities.

The raw-data generator uses a fixed random seed. Run the generator first and then run the preparation script from the project root to reproduce the dataset and cleaned output.
